# What is Generative AI?

Generative AI is a type of Artificial Intelligence that can create new content such as:

* Text
* Images
* Music
* Videos
* Code

Unlike traditional AI systems that only analyze data, Generative AI can generate completely new outputs based on the data it has learned.

### Examples of Generative AI Tools

* ChatGPT – Generates human-like text responses
* Gemini – AI assistant developed by Google
* GitHub Copilot – Helps developers write code
* Midjourney – Creates AI-generated images
* DALL·E – Generates images from text prompts

---

# How Generative AI Works

Generative AI models are trained using massive datasets collected from books, websites, articles, images, and code.

The AI learns:

* Patterns
* Language structure
* Context
* Human conversation style

When a user gives a prompt, the AI predicts the most suitable response based on what it learned during training.

# Important Concepts in Generative AI

## 1. Prompt

A prompt is the input given to an AI model.

### Example

```python
"Write a short story about space"
```

The quality of the prompt often affects the quality of the AI response.

---

## 2. Large Language Model (LLM)

An LLM is a powerful AI model trained on huge amounts of text data.

### Examples

* GPT
* Gemini
* Claude
* Llama

These models can understand and generate human-like language.

---

## 3. Prompt Engineering

Prompt engineering means writing effective prompts to get better results from AI.

### Basic Prompt

```python
"Explain Python"
```

### Better Prompt

```python
"Explain Python for beginners with simple examples"
```

Better prompts produce more accurate and useful responses.

---

## 4. Tokens

AI models break text into smaller units called tokens.

### Example

```python
"Hello world"
```

may become:

```python
["Hello", "world"]
```

Tokens help the model process language efficiently.

---

## 5. Fine-Tuning

Fine-tuning is the process of training an already existing AI model on custom data for a specific task.

Example:

* Training an AI model only on medical data for healthcare applications.

# Conditional Statements

Conditional statements are used for decision making.

```python

    print("Eligible")

    print("Not Eligible")
```

---

# Loops in Python

Loops are used to repeat tasks.

## For Loop

```python
for i in range(5):
    print(i)
```

---

## While Loop

```python
x = 1
while x <= 5:
    print(x)
    x += 1
```
